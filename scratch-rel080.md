# OmniWork v0.8.0 — Recipes + Image input

## New

### ⚡ Recipes
One-click agent tasks. Hit **⚡ recipes** in the sidebar and pick:
**Tour the codebase · Write tests · Find & fix bugs · Refactor pass · Generate docs ·
Add a feature · Explain this error · Speed it up.** Each launches in a fresh session, and
several fan out to parallel subagents via the Agent Deck.

### 🖼️ Image input
Paste a screenshot straight into the composer (⌘/Ctrl+V). The agent sees it — great for
"why does this look wrong?", error screenshots, or design mockups. (Uses a vision-capable
model via `auto` routing.)

## Everything else
Cowork · Agent Deck · MCP gallery · delegate-to-Claude-Code · streaming · approvals (with diffs) ·
undo · project memory (AGENTS.md) · dynamic model list · session persistence · web tools.

## Install
- **Windows:** `OmniWork.Setup.0.8.0.exe` below.
- **macOS / Linux:** build from source.

MIT. Free, local, zero setup.
